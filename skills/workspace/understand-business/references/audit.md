# Business Understanding Audit Protocol

This file is for the main agent to read and execute after completing the report checklist. Do not hand it unchanged to a specialist subagent.

## Prepare the independent review

Run the `brainstorm` skill and provide the specialists with:

- the completed draft
- `references/checklist.md`
- the metrics spine
- the evidence briefs
- paths to the primary source folder

Ask for material, citation-backed criticisms only. Do not assign predetermined bull, bear, moat, or accounting personas; the purpose is to surface blind spots rather than manufacture balanced theater.

Ask reviewers to identify:

- the report section or checklist item affected
- severity: critical, analytical, consistency, or minor
- the evidence supporting the criticism
- the causal consequence if the criticism is correct
- the smallest correction that would resolve it

## Run the Munger bias check

Read `references/bias-definitions.md`. Identify only tendencies with a plausible causal role in a substantive judgment. Do not force a bias into every section.

When a tendency materially affects the analysis, add this compact callout at the relevant point in the report:

> **Bias check — [Munger tendency]:** “[Short relevant definition.]” Here it could pull us toward [specific conclusion]. Countercheck: [evidence, base rate, or procedure used].

Use the quoted definition to make the mechanism understandable. Do not create a separate bias section or appendix glossary. Consider whether several tendencies reinforce one another into a lollapalooza effect.

## Adjudicate the review

The main agent owns the judgment. Specialist agreement is not evidence.

For every material criticism:

1. Check the cited source and any contradictory evidence.
2. Mark the criticism `accept`, `modify`, or `reject`.
3. Explain the disposition briefly.
4. Record the evidence checked.
5. State the exact report change, if any.

Reject requests that merely add volume, repeat an existing point, force an inapplicable metric, or turn the report into a recommendation.

## Revise once

Make one targeted substantive revision focused on the few criticisms that materially change understanding. Re-run the affected checklist items and verify that no new contradiction was introduced.

Save `audits/understanding-audit.md` with:

- review brief supplied to brainstorm
- consolidated material criticisms
- disposition and evidence checked for each
- bias checks considered and any inline callouts added
- edits made
- unresolved disagreements or evidence gaps
