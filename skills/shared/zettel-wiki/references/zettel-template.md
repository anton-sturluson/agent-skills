# Zettel Template

Use this format for new zettels in `zettels/`.

```markdown
---
id: "YYYYMMDDHHmm"
title: "Short descriptive title"
tags: ["#topic-one", "#topic-two"]
created: YYYY-MM-DD
source: "path/to/raw/source/file or URL"
---

# [Title]

[Body: one thought, claim, or insight in your own processed words. Not a copy-paste — synthesized, contextualized. Answers "why does this matter?" and "how does this connect?" Stands alone as a single atomic thought.]

## Connections

→ [ID](ID.md) — [Why this connection matters. Not just "related to" but the specific nature of the link.]

## Related

- [Structure Note Title](../pages/path/to/page.md)

## Evidence

- [Source Title](path/to/raw/source) — [specific location: page, section, paragraph, table]
```

## Rules

- **One thought per file.** Two ideas = two zettels.
- **Timestamp ID:** `YYYYMMDDHHmm`. If creating multiple in the same minute, increment by one minute.
- **Title:** Short, descriptive, standalone.
- **Tags:** 2–5 hashtags. Don't over-tag.
- **Source:** Path to raw source or URL. Omit for conversation or synthesis insights.
- **Body:** Processed knowledge. Synthesize, contextualize. Don't just excerpt the source.
- **Connections:** Bidirectional. Update both sides. Every connection has explicit context explaining why.
- **Related:** Links to structure notes this zettel supports.
- **Evidence:** Specific citations back to raw sources.
